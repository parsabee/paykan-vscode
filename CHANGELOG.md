# Changelog

## [0.0.1] - 2026-10-07

### Added

- Syntax highlighting for `.pkn` files: keywords, literals (escapes, floats, tuple
  indices), built-in types and functions, declarations, generics, enum variants,
  module paths and operators. `mov` is marked as invalid, since the language
  removed it.
- Language configuration: `//` comment toggling, bracket matching, auto-closing
  pairs and brace indentation.
